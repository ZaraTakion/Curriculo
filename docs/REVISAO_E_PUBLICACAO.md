# Revisão antes de candidaturas

Use esta lista antes de cada candidatura, mesmo quando o CI estiver verde.

- [ ] Confirmar nome completo exibido e contato público atualizado.
- [ ] Validar instituição, nome exato do diploma e ano de conclusão.
- [ ] Conferir a autoavaliação de inglês e sua compatibilidade com entrevistas.
- [ ] Conferir que cada tecnologia do currículo é demonstrável nos repositórios.
- [ ] Distinguir os projetos pessoais/acadêmicos de experiência profissional contratada.
- [ ] Não afirmar que sistemas estão em produção sem evidência.
- [ ] Manter links válidos e sem apontar para branches provisórias quando disponíveis na `main`.
- [ ] Rodar `python scripts/build_resumes.py` e `python scripts/validate_release.py`.
- [ ] Inspecionar os PDFs em tamanho de impressão; exigir uma página por idioma e leitura confortável.
- [ ] Revisar DOCX em um editor compatível e verificar links clicáveis.
- [ ] Conferir se o README aponta para os arquivos efetivamente versionados.
- [ ] Antes de disponibilizar o repositório publicamente, confirmar que nenhum documento expõe CPF, endereço completo, telefone privado ou data de nascimento.

**Observação:** o CI verifica características técnicas dos arquivos, não veracidade de declarações nem aprovação de uma candidatura. O repositório é público e pode ser indexado por buscadores.
